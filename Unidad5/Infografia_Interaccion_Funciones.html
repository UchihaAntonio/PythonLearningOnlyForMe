🔄 Interacción entre Funciones en Python

Guía para programadores intermedios

¿Qué es la interacción entre funciones?

Cuando una función llama a otra función, o cuando el resultado de una función se pasa como argumento a otra función, estamos creando una interacción entre funciones. Este patrón es fundamental para escribir código modular, reutilizable y fácil de mantener.

🔹 Funciones como argumentos

Una función puede recibir otra función como parámetro y ejecutarla internamente.

🔹 Funciones que retornan funciones

Una función puede crear y retornar una nueva función.

🔹 Encadenamiento de funciones

El resultado de una función se pasa directamente como argumento a otra función.

🔹 Funciones anidadas

Una función puede definir otras funciones dentro de ella misma.

def procesar_lista(lista, operacion): """Aplica una operación a cada elemento de la lista""" return [operacion(elemento) for elemento in lista] def duplicar(x): return x * 2 def cuadrado(x): return x ** 2 def es_par(x): return x % 2 == 0 # Usando diferentes funciones como argumentos numeros = [1, 2, 3, 4, 5] # Aplicar diferentes operaciones duplicados = procesar_lista(numeros, duplicar) print(duplicados) # [2, 4, 6, 8, 10] cuadrados = procesar_lista(numeros, cuadrado) print(cuadrados) # [1, 4, 9, 16, 25] # Con funciones lambda (funciones anónimas) dobles = procesar_lista(numeros, lambda x: x * 2) print(dobles) # [2, 4, 6, 8, 10] # Filtrar usando una función que retorna booleano pares = list(filter(es_par, numeros)) print(pares) # [2, 4]
Permite reutilizar lógica de procesamiento Patrón común en map(), filter(), sorted() Hace el código más flexible y genérico

def crear_multiplicador(factor): """Crea una función que multiplica por un factor específico""" def multiplicar(numero): return numero * factor return multiplicar def crear_validador(tipo): """Crea un validador según el tipo especificado""" def validar(valor): if tipo == "email": return "@" in str(valor) and "." in str(valor) elif tipo == "numero": return isinstance(valor, (int, float)) elif tipo == "texto": return isinstance(valor, str) and len(valor) > 0 return False return validar # Crear funciones especializadas duplicar = crear_multiplicador(2) triplicar = crear_multiplicador(3) mitad = crear_multiplicador(0.5) print(duplicar(5)) # 10 print(triplicar(5)) # 15 print(mitad(10)) # 5.0 # Crear validadores específicos validar_email = crear_validador("email") validar_numero = crear_validador("numero") print(validar_email("test@example.com")) # True print(validar_email("invalido")) # False print(validar_numero(42)) # True print(validar_numero("42")) # False # Ejemplo avanzado: combinar con map numeros = [1, 2, 3, 4, 5] resultados = list(map(crear_multiplicador(10), numeros)) print(resultados) # [10, 20, 30, 40, 50]
Las funciones internas recuerdan el entorno donde fueron creadas Patrón de diseño Factory (fábrica) Muy útil para configuraciones personalizadas

🎯 Buenas Prácticas

✓ Principio de Responsabilidad Única

Cada función debe hacer una sola cosa y hacerla bien.

✓ Nombres descriptivos

Usa nombres que indiquen claramente qué hace la función.

✓ Documenta el flujo

Usa docstrings para explicar cómo interactúan las funciones.

✓ Evita acoplamiento excesivo

Las funciones deben ser independientes y reutilizables.
